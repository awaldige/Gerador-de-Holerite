# 📑 AW Gerador de Holerite

Aplicação web desenvolvida para simulação e geração de demonstrativos de pagamento, contemplando holerites mensais, férias e décimo terceiro salário.

O projeto conta com interface moderna e responsiva, cálculos automatizados, organização de proventos e descontos, geração de duas vias do documento e exportação em PDF.

Desenvolvido pela **AW TECHNOLOGY** com HTML5, CSS3 e JavaScript puro, sem necessidade de backend ou instalação de dependências locais.

## 🧾 Visão Geral

O AW Gerador de Holerite permite simular demonstrativos de pagamento de maneira prática e organizada.

O sistema disponibiliza três modalidades:

- Holerite mensal.
- Holerite de férias.
- Holerite de décimo terceiro salário.

Cada demonstrativo apresenta informações do colaborador, proventos, descontos, total de vencimentos, total de descontos e valor líquido a receber.

---

## ⚙️ Funcionalidades

### 📄 Geração de Holerites

- Geração de holerite mensal.
- Geração de demonstrativo de férias.
- Geração de demonstrativo de décimo terceiro salário.
- Identificação do colaborador e da empresa.
- Organização dos lançamentos financeiros.

### 🧮 Cálculos Automatizados

- Simulação de INSS.
- Simulação de IRRF.
- Dedução por dependentes.
- Vale-transporte (VT).
- Vale-refeição (VR).
- Adiantamentos salariais.
- Plano de saúde.
- Seguro de vida.
- Contribuição negocial.
- Outros descontos personalizados.

### 📤 Recursos e Documentos

- Geração de duas vias do holerite.
- Exportação dos demonstrativos em PDF.
- Layout preparado para impressão em formato A4.
- Campo para assinatura do colaborador.
- Data de recebimento.
- Destaque visual para o valor líquido a receber.

### 🧹 Gerenciamento dos Formulários

- Botão para limpar cada formulário.
- Restauração dos campos para os valores iniciais.
- Limpeza automática do demonstrativo anterior.
- Ocultação do botão de exportação após a limpeza.
- Atualização dos campos condicionais de benefícios e descontos.

### 📱 Interface e Usabilidade

- Layout moderno e profissional.
- Design responsivo para desktop e dispositivos móveis.
- Navegação por abas.
- Campos condicionais para facilitar o preenchimento.
- Organização visual de proventos e descontos.

## 💻 Como Executar Localmente

**1. Clone o repositório:**

```bash
git clone https://github.com/awaldige/Gerador-de-Holerite.git
```

**2. Acesse a pasta:**

```bash
cd Gerador-de-Holerite
```

**3. Execute a aplicação:**

Abra o arquivo `index.html` em qualquer navegador moderno.

Não é necessário instalar dependências locais, configurar banco de dados ou utilizar backend.

## ⚠️ Aviso Importante

Este projeto possui finalidade demonstrativa, educacional e de portfólio.

Os cálculos de INSS, IRRF e demais valores são utilizados para simulação e não devem ser considerados como apuração oficial de folha de pagamento.

O sistema não substitui softwares contábeis, sistemas oficiais de folha de pagamento ou a orientação de profissionais especializados.

Não utilize os demonstrativos gerados como documentos oficiais ou comprovantes legais de pagamento.
